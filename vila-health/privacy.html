Política de privacidade

Vila Health é uma aplicação pessoal, usada apenas pelo seu dono.

Que dados lê

Com autorização do utilizador, lê em modo de leitura dados do Google Health: sono, atividade e exercício, métricas e medições de saúde, nutrição e perfil.

Para que servem

Servem só para produzir resumos de saúde para o próprio utilizador.

Onde ficam

Os dados ficam no computador do utilizador. Não são vendidos, não são partilhados com terceiros e não são usados para publicidade.

Como retirar o acesso

O acesso pode ser retirado a qualquer momento em myaccount.google.com/permissions. Os dados locais apagam-se removendo os ficheiros da aplicação.

O uso de informação recebida das APIs da Google respeita a Google API Services User Data Policy, incluindo os requisitos de uso limitado.
